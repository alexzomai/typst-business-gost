# Происхождение и изменения

Этот шаблон является адаптацией проекта **typst-gost/modern-g7-32**
(https://github.com/typst-gost/modern-g7-32), коммит
`6fe1cb2ef8f09b1947b241c58b47e7858598f3ce`, лицензия GPL-3.0-only.
Авторы upstream по `typst.toml`: Pavel Eliseev, Arseniy Zasypkin.
Полный текст лицензии: `LICENSE` (без изменений, байт в байт как в upstream).

Адаптированный шаблон распространяется на тех же условиях, GPL-3.0-only.
Изменения внесены в 2026 году для работы с деловыми документами.

## Что взято из upstream

| Файл здесь | Источник | Статус |
|---|---|---|
| `src/utils.typ`: `fetch-field` | `src/utils.typ` | без изменений |
| `src/utils.typ`: `unbreak-name` | `src/utils.typ` | без изменений |

| `src/style.typ` | `src/style.typ` | изменён: нумерация вверху страницы, расчёт интервала по базовой линии, убраны оглавление, рисунки, список источников, колонтитул с городом и годом |
| `src/lib.typ` | `src/lib.typ` | изменён: вместо титульного листа и списка исполнителей настройка деловых документов |

Нормализация аргументов через `fetch-field` используется для полей и размеров шрифта (`src/validate.typ`).

Титульные листы и их шаблоны, реферат, список исполнителей, академический список источников, приложения в академическом смысле, принудительные разрывы страниц перед главами, брендинг прежнего стандарта, изображения, логотипы, примеры и референсные снимки тестов, PDF стандарта.
