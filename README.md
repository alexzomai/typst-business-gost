# typst-business-gost: шаблон деловых документов (Typst)

Шаблон для договоров, актов и счетов на оплату. Оформление построено по ГОСТ Р 7.0.97-2025 (разделы 3 и 6.1, см. `docs/standard-matrix.md`). Основа: часть кода из typst-gost/modern-g7-32 под GPL-3.0, см. `NOTICE.md`.

Поддержка стандарта ограничена перечисленными в `docs/standard-matrix.md` пунктами (3.2 до 3.5, 5.17 до 5.19, 5.22, 6.1). Шаблон не гарантирует соответствие стандарту и не заменяет юридическую проверку документа. Что проверено и что остаётся на авторе: `docs/conformity-audit.md`.

## Умолчания
A4, поля 30/15/20/20 мм (левое, правое, верхнее, нижнее), Liberation Serif 14 пт, интервал 1,5, абзацный отступ 1,25 см, выравнивание по ширине. Нумерация со второй страницы по центру верхнего поля, первая страница без номера.

## Быстрый старт
```typ
#import "../src/export.typ": *
#show: business-doc.with(title: "Договор")

#document-heading("ДОГОВОР", number: "[номер]", subject: "об оказании услуг",
  place: "[Место]", date: "[Дата]")

= Предмет договора
1.1. Текст пункта.

#signatures(
  left: (position: [Исполнитель], name: "[Инициалы Фамилия]"),
  right: (position: [Заказчик], name: "[Инициалы Фамилия]"),
)
```
Примеры: `examples/contract.typ`, `act.typ`, `invoice.typ`, `long-duplex.typ`.

## Параметры `business-doc`
| Параметр | По умолчанию | Проверка |
|---|---|---|
| `text-size` | `(default: 14pt, small: 10pt)` | основной 12, 13 или 14 пт; уменьшенный меньше основного и не менее 8 пт |
| `line-spacing` | `1.5` | от 1 до 1,5 |
| `margin` | `(left: 30mm, right: 15mm, top: 20mm, bottom: 20mm)` | не менее 20/10/20/20 мм |
| `long-retention` | `false` | при `true` левое поле не менее 30 мм |
| `duplex` | `false` | зеркальные поля для двусторонней печати, номер по центру листа |
| `indent` | `1.25cm` | ровно 1,25 см |
| `strict-font-size` | `true` | `false` снимает ограничение 12 до 14 пт |
| `heading-align` | `"indent"` | `"indent"` или `"center"` |
| `paper` | `"a4"` | только A4 |

Недопустимые значения останавливают компиляцию с понятным сообщением. Интервал считается как расстояние между базовыми линиями: размер шрифта умножить на `line-spacing` (14 пт и 1,5 дают 21 пт). Это выбранная модель; текст стандарта не определяет интервал таким образом, поэтому соответствие модели нормативным «одному» и «1 до 1,5 интервалам» не доказано. Это не то же самое, что «множитель» в Word.

## Компоненты
`document-heading`, `requisites`, `requisites-pair`, `form-requisite`, `signatures`, `contract-appendix-header`, `data-table`, `small-text`, `compact`.

- `document-heading(kind, number:, subject:, status:, place:, date:)`: вид и номер по центру, `subject` слева от границы поля (п. 5.17). Строка `subject` должна начинаться с «о» или «об»; для `content` проверка на авторе.
- `form-requisite("corner" или "longitudinal", label, ..lines, align: left)`: зона реквизита бланка 8 или 12 см (п. 3.5). Текстовые токены шире зоны вызывают ошибку компиляции, без обрезки; автор должен сократить их или добавить явный перенос. Для произвольного `content` (неразрывные коробки, ручные смещения, токены из нескольких разноформатных фрагментов) строгая ширина не гарантируется; требуется проверка PDF. Та же проверка и ограничение действуют для отметки о приложении. Обычный `requisites` зоной не ограничен (банковские блоки сторон).
- `signatures(left:, right:, layout: "horizontal" или "vertical")`: `horizontal` для равных должностей рядом, `vertical` для разных должностей одна под другой в заданном порядке (п. 5.22). Подпись набирается основным размером с одинарным интервалом. Запись «И.О. Фамилия» на авторе.
- `contract-appendix-header(number, title, to:, base-kind:, base-date:, base-number:, new-page:)`: отметка «Приложение № …» с ссылкой на основной документ в правом верхнем углу, блок 8 см (п. 5.19); без `to` и `base-*` подставляется заглушка «[вид, дата и номер основного документа]».
- Уровней заголовков не более четырёх (п. 5.18), пятый останавливает компиляцию.

## Использование в другом документе
Импортируйте `src/export.typ` по относительному пути. Компилируйте с корнем, включающим шаблон:
```
typst compile --root . examples/contract.typ build/contract.pdf
```

## Установка и проверка
```
uv venv .venv
uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
```
Результаты и изображения страниц лежат в `build/tests/` (в Git не попадают).
